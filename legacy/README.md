# Legacy snapshot

Exact snapshot of the production portfolio at https://aishwarya-dev-ten.vercel.app/
taken on 2026-09-25, before the redesign. The original Create React App source was not
available, so this folder is the checkpoint of record.

- `build/` — the deployed CRA build as served (HTML, JS chunks, CSS, asset manifest).
- `public/` — every public asset served by the site (project screenshots, logo, favicon,
  manifest, robots.txt, and the placeholder `resume.pdf`).
- `content-extracted.json` — all portfolio content (profile, stats, 18 projects, 46 skills,
  categories, section copy, EmailJS + call-widget config) extracted verbatim from the bundle.
  This is the source of truth for the redesign's content.
